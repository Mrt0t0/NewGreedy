📋 Log fields
Field / FlagDescription
[SEED] / [DOWN]Torrent mode (pure seeder or downloader)
DL:Cumulative download tracked by the engine
UL:Cumulative upload reported to tracker
+ΔULUpload increment added at this announce
R:Current ratio (UL / DL)
ETA:~XaEstimated announces to reach target ratio
#NTotal announce count for this torrent
[STAG]Deliberate stagnation cycle — no upload added
[STALL_NET]Network stall — N consecutive announces with DL=0
[STALL_ALGO]Algorithm stagnation active
[TARGET_REACHED]Target ratio reached — injection stopped
[PURGED]Torrent removed from stats after event=stopped
[STOPPED]event=stopped received — retired once stopped_purge_delay has passed
[RESUMED]It announced again inside that delay — counters kept
[DL_CAP]Reported download held back so left falls at a credible speed
[GLOBAL_CAP]Global tracker ratio cap reached — upload reduced
[TRACKER_DOWN]Tracker entering backoff after repeated 5xx errors
[UDP_BYPASS]UDP tracker detected — announces are not intercepted
[PAUSED]Injection suspended for this torrent
[DRY-RUN]Simulation mode — the announce was not modified
[IDENTITY]Session client, peer_id and port chosen at startup
[DESYNC]Another torrent announced to the same tracker within desync_min_gap
[BURST]Startup window — injected upload is still ramping up
[CONTROL]Pause/override/tag file reloaded
[WATCH]Torrent auto-imported from the watch folder
[CUMUL_PURGE]Inactive tracker dropped from the cumulative ratio
[AUTO-PURGE]No announce for inactive_purge_hours — moved to the trash
[TRASH]Trash entries older than trash_retention_days deleted for good
[RESTORE]Stats replaced from a backup, or torrents brought back from the trash
[BACKUP]Backup archive written (auto, manual, pre-update, pre-restore)
[CONFIG]config.ini reloaded live, or merged after an upgrade
[REGISTRY]torrent_registry.json reloaded — sizes corrected if needed
[ENGINE_FAILED]The engine could not start — announces get a tracker error until it is fixed
[TOKEN]Web UI token rotated or removed
